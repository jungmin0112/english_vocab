## 확정 범위

- quiz.py에서 F-03~F-06(문제 진행·채점·결과·자기평가)을 구현한다.
- 출제 대상 선정(F-09), FSRS 갱신(F-07), 저장(F-08)은 이번 구현 범위에서 제외한다.
- 연결 계약을 문서화하고 샘플 데이터로 퀴즈를 실행·검증한다.
- 한 회차는 선정된 단어를 중복 없이 최대 15문제 진행한다.
- 등록된 한국어 뜻 중 하나와 띄어쓰기를 무시하고 일치하면 정답이다.
  빈 답과 미등록 동의어는 오답이다. 문제별 결과를 즉시 표시한다.
- 종료 후 문제 수·정답 수·오답 수, 단어별 입력 답과 정오를 표시한다.
  오답에는 등록된 뜻을 함께 표시한다.

## 확정된 자기평가와 중단 동작

- 결과 표시 후 정답은 Good, 오답은 Again을 기본 평가로 둔다.
- 정답 단어의 번호를 선택하여 Hard 또는 Easy로 변경한다.
- Enter로 최종 확정한다. 변경하지 않은 정답은 Good을 유지한다.
- 잘못된 선택은 재입력받는다.
- 확정 전에 Ctrl+C 또는 입력 종료가 발생하면 회차를 취소한다.
  취소한 회차는 학습 상태에 반영하지 않는다.

## 확정된 JSON 구조

사용자가 영어 키 → 단어 정보 객체 → meanings 리스트 구조를 승인했다.

```json
{"apple": {"meanings": ["사과"]}, "run": {"meanings": ["달리다", "운영하다"]}}
```

영어 키는 앞뒤 공백을 제거한 소문자로 저장한다. 뜻은 하나 이상의 비어 있지 않은
문자열이다. 출력용 원문은 보존하고 채점 비교 시에만 모든 공백 문자를 제거한다.
UTF-8 JSON을 json.load로 읽는다. 동일 JSON 키, 잘못된 자료형, 빈 뜻은 거부한다.
추가 정보 필드는 허용하되 퀴즈에서는 해석하지 않는다. FSRS 저장 필드는 미정이다.

## 구현된 함수 계약

- `load_words(path)`: JSON 파일을 검증하여 단어 딕셔너리를 반환한다.
  파일 부재·읽기 실패는 OSError 계열, 잘못된 내용은 ValueError 계열로 전달한다.
- `is_correct(answer, meanings)`: 등록 뜻 중 하나와 일치하는지 bool로 반환한다.
- `run_quiz(words, selected_words, read=input, write=print)`: 단어 딕셔너리와
  선정된 영어 키 목록을 받아 목록 순서대로 진행한다. 중복을 제거하고 최대 15개를 사용한다.
  등록되지 않은 출제 키는 ValueError로 거부한다.
- 확정 시 `english`, `answer`, `correct`, `meanings`, `rating`을 가진 결과 목록을 반환한다.
  대상이 없으면 빈 목록, 중단하면 None이다. 입력 단어 데이터는 변경하지 않는다.
- `show_results(results)`: 전체·정답·오답 수 및 단어별 결과를 출력한다.

결과 반환 형식과 selected_words 연결은 이번 구현의 계약으로, 팀원 통합 확인은 아직 필요하다.
호출자는 확정된 비어 있지 않은 결과에 대해서만 FSRS 갱신과 저장을 수행해야 한다.
퀴즈 모듈의 JSON 읽기는 단독 실행용 경계이며 공통 storage.py와 통합 시 중복 책임을 조정한다.

## 단독 실행과 통합 경계

CLI에서는 JSON 경로와 출제할 영어 키를 직접 지정한다. `--demo`는 샘플 파일 순서로
최대 15개를 진행하는 실행 옵션이다. 실제 복습 우선순위나 복습 예정일을 계산하지 않는다.
대상 미지정 시 임의로 전체 단어를 복습 대상으로 취급하지 않는다.
평가 UI는 Hard/Easy 변경 외에 Good으로 되돌리는 선택도 제공한다.
파일 오류는 안내 후 종료 코드 1로 종료하며 파일을 덮어쓰지 않는다.

## 검증 계획

정답·여러 뜻·띄어쓰기·빈 답·미등록 동의어, 결과 집계,
Good/Again 기본값, Hard/Easy 변경, 잘못된 평가 입력,
최종 확정 및 확정 전 중단을 검증한다.
2026-11-14 이 작업 트리의 독립 가상환경(Python 3.11.2)에서
`.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -v`를 실행해 10개 테스트가 통과했다.
최대 문제 수·중복 제거·대상 없음·입력 데이터 보존·손상 파일도 검증했다.
FSRS 갱신·저장·재시작 복원은 구현 범위 밖이며 통합 검증하지 않았다.
